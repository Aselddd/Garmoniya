# Гармония
Данный проект представляет собой веб-сервис  для автоматической оценки факторов туристической привлекательности отелей на основе анализа текстов отзывов. 

Система собирает отзывы с популярных платформ выполняет их предобработку методами обработки естественного языка , извлекает ключевые аспекты с помощью алгоритма YAKE, определяет тональность и строит математическую модель (Ordered Logit) для расчета  индекса привлекательности отеля.

## Основные возможности (Features)
* **Парсинг отзывов и оценок** об отелях Краснодарского края и Республики Крым.
*   **Предобработка текста (NLP):** Очистка данных, токенизация, лемматизация и удаление предлгов/союзов использованием библиотек `pymorphy3` и `NLTK`.
Автоматическое выделение ключевых факторов из текстов отзывов с помощью алгоритма `YAKE`.
*   **Анализ тональности:**  с использованием нейросетевой мо 
Построение модели `Ordered Logit` для определения веса  каждого выявленного фактора.
*   **Веб-интерфейс:** Просмотр списка отелей, фильтрация и визуализация факторов привлекательности (реализовано на Flask).
